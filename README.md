# 🧬 TF Binding Site Classification

Proyecto de bioinformática enfocado en la **clasificación de sitios de unión a factores de transcripción en bacterias** utilizando técnicas de machine learning.

---

##  Descripción

Este proyecto implementa un flujo completo de análisis de datos biológicos para identificar patrones en secuencias de ADN y predecir sitios de unión a factores de transcripción.

Se abordan las siguientes etapas:
- Preprocesamiento de datos biológicos
- Extracción de características
- Entrenamiento de modelos de clasificación
- Evaluación del modelo

---

##  Metodología

1. Limpieza y procesamiento de secuencias de ADN  
2. Transformación de datos para su uso en modelos de machine learning  
3. Entrenamiento de modelos de clasificación  
4. Evaluación del desempeño del modelo  

---

## 🛠️ Tecnologías utilizadas

- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Jupyter Notebook  

---

##  Resultados

- Accuracy: [0,96]  
- Observaciones:
  - El modelo permite identificar patrones en secuencias biológicas
  - El rendimiento depende de la calidad del dataset
